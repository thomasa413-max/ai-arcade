Die technischen Kriterien werden für jedes Spiel mit denselben Tests auf Smartphone und Desktop geprüft. Den Spielspaß bewertet der Projektverantwortliche nach dem Spielen. Die Werte von Hive Breach und Relic Run sind vorläufig.

So läuft es ab

Lieferdisziplin zählt so viel wie die Spiele, deshalb folgt jedes Spiel demselben kleinen Prozess.

  1. Ein klares BriefingJedes Vorhaben beginnt mit einem schriftlichen Briefing: was entsteht, für wen und woran man «fertig» erkennt. Eine generische Vorlage und Zusatzmodule finden Sie im Baukasten.
  2. Zeitlich begrenzte EntwicklungJedes Vorhaben erhält eine feste Zahl von Iterationen. Zeit, Prompts und Kosten werden protokolliert.
  3. Test auf dem SmartphoneJedes Spiel wird vor der Veröffentlichung auf einem echten Smartphone und Desktop geöffnet.
  4. Bewerten und veröffentlichenBewertet nach den sechs Kriterien oben, mit Notizen dazu, was funktionierte und was korrigiert werden musste.

Eine Briefing-Vorlage zum Start finden Sie auf der Seite zum Entwicklungs-Kit.
