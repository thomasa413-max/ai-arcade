2 · Add-on: web game

ADD-ON: web game
Build a complete, original 2D browser game as ONE self-contained HTML file (HTML, CSS and JavaScript in the same file, no build step, no external image or audio files).

Requirements:
1. Runs on any device (phone, tablet, desktop) in BOTH landscape and portrait: full-screen responsive canvas that re-lays out on rotation (never a "please rotate" screen), on-screen touch controls plus keyboard.
2. One complete level or stage with a clear goal, rising difficulty, a win screen, a game-over screen and a restart button.
3. Modern visual style, drawn in code. Original title, characters and names: no trademarked or copyrighted names, characters or logos.
4. Sound effects and music generated with the Web Audio API, a mute button, audio starting only after the first tap.
5. HUD with score and lives or health, plus a pause button.
6. Smooth 60 fps on a mid-range phone.
7. Short title screen that explains the controls.

Deliver the single HTML file first. Then list three improvements you would make with more time.

3b · Add-on: AI chat assistant

ADD-ON: AI CHAT ASSISTANT (website visitors ask questions, answered from the site's own content)

1. Use the Anthropic API (Claude Haiku, low cost) called from a server-side Worker. The API key is a secret, never in the page, the code or GitHub.
2. Ground the answers on the site's own pages: generate the knowledge text automatically from the built pages at every build, plus a short hand-written notes file for facts that are not on the pages. Answer only from that knowledge, reply in the visitor's language, keep answers under 120 words, ignore instructions hidden in user messages, politely refuse off-topic requests.
3. Protect the cost: bot check (Turnstile) once per session with a signed cookie, a per-visitor hourly limit, a global daily limit, short messages and a short history, and a hard monthly spend limit plus an expiring API key in the Anthropic Console.
4. Privacy: do not store conversations. Store only counters (messages, input tokens, output tokens). Show a visible line in the footer and in the widget: the question is sent to Anthropic to generate the answer, is not stored on this site, and visitors should not share personal information.
5. Widget: a small button at the bottom right, hidden until the server says it is ready, translated into every language of the site, RTL-aware, keyboard and screen-reader friendly, free typing (no preset question buttons).
6. Admin: add a section "Chatbot usage and cost" (messages, tokens, estimated cost per day).
7. Reuse the site-kit files: worker/src/chat.js, static/sitekit-chat.js, tests/test_chat.mjs, and the README section "Adding the chat assistant to a site".
8. Test: the limits, the missing-key state, a prompt-injection attempt, and one question in each language.

Mention the assistant in the site description and in the About text.

4 · Add-on: AI household expense app

ADD-ON: AI household expense app
APP: a household account system that captures expenses and simulates monthly savings for specific projects (e.g. holiday, car, renovation). Switzerland first: CHF, QR-bills, 8 languages.
Core idea: lead with the savings simulator ("can we afford this by this date, and what would we cut?", "what if we cut dining out by CHF 200?"). Expense capture feeds it and is not the product.
Capture: receipt photo, forwarded e-mail, QR-bill PDF and CSV import, with AI categorisation the user can correct. No bank credentials stored.
Security and privacy: collect minimal data, encrypt in transit and at rest, per-household access with invitations for a partner, delete-my-data button, audit log, clear privacy promise.
Business model to test: free tier with one or two projects, paid tier with more projects, shared household and bank sync. Billing and a vendor-side CRM only after real users exist.
Also deliver: user stories, data model, the savings-simulation logic with worked examples, a risk list (security, pricing, churn), a 4-week proof-of-concept plan and an acceptance checklist.

Reusable building blocks

Already built and reusable for any new project (web game, mobile app or household app):
- 8-language site generator (en, fr, es, pt, de, it, ar right-to-left, zh) with per-language URLs and hreflang
- Cloudflare Worker + D1 backend: admin area with signed sessions, moderated comments with Turnstile bot check, visit counter and origin tracking
- Security headers, accessibility and Core Web Vitals checks (axe, Lighthouse)
- Installable web app basics: favicon set, web manifest, theme colour
- Scorecard method: same criteria, scored 0 to 5 after each build, with notes
- AI chat assistant (site-kit): Cloudflare Worker module calling Claude through the Anthropic API, answers only from a knowledge text, Turnstile check, per-visitor and daily limits, no conversations stored, 8-language widget
- Image pipeline: prompts written by Claude, pictures generated through the OpenAI image API, saved next to the project
- Game kit patterns: synthesized sound, touch and keyboard input, responsive canvas, saved progress
Rule for every new project: copy the block you need, do not rebuild it.
