Build kit

Every build starts from its own written brief. Use the generic template for any project, add the add-on that fits (web game, mobile app or household project), then see the game briefs used so far. New briefs are added here as new builds start.

1 · Generic starter template (any project)

Act as a senior specialist for this kind of project. Before building, ask me up to 5 short questions ONLY if something essential is missing; otherwise start.

PROJECT: [one sentence: what we are making]
WHO IT IS FOR: [person or audience, and where they will use it]
GOAL: [what "done" looks like, in one sentence]
CONSTRAINTS: [budget, deadline, tools, skills, size, rules to respect]
MUST HAVE: [3 to 5 requirements]
NICE TO HAVE: [optional extras]
OUT OF SCOPE: [what to leave out]

Deliver: (1) the first complete version, (2) a short list of assumptions you made, (3) three improvements you would make with more time, (4) a checklist I can use to verify it is done.

2 · Add-on: web game

ADD-ON: web game
Build a complete, original 2D browser game as ONE self-contained HTML file (HTML, CSS and JavaScript in the same file, no build step, no external image or audio files).

Requirements:
1. Runs on any device (phone, tablet, desktop) in BOTH landscape and portrait: full-screen responsive canvas that re-lays out on rotation (never a "please rotate" screen), on-screen touch controls plus keyboard.
2. One complete level or stage with a clear goal, rising difficulty, a win screen, a game-over screen and a restart button.
3. Modern visual style, drawn in code. Original title, characters and names: no trademarked or copyrighted names, characters or logos.
4. Sound effects and music generated with the Web Audio API, a mute button, audio starting only after the first tap.
5. HUD with score and lives or health, plus a pause button.
6. Smooth 60 fps on a mid-range phone.
7. Short title screen that explains the controls.

Deliver the single HTML file first. Then list three improvements you would make with more time.

GAME: [paste this game's line from below, or write a new one]

3 · Add-on: mobile app

ADD-ON: mobile app
Platform: [iOS, Android or installable web app (PWA)]. Screens: [list the 3 to 6 screens and what each does].
Requirements: works offline for the core task; data stays on the device unless stated; touch targets of at least 44 px; supports dark mode and large text; no permissions beyond what the feature needs; fast first launch.
Also deliver: a screen-by-screen flow, a data model, an empty-state and error-state for every screen, and a store-readiness checklist (icon sizes, privacy note, screenshots).

4 · Add-on: household project

ADD-ON: household project
Where: [room, area or item]. Size and measurements: [dimensions]. Budget: [amount] and deadline: [date]. Who does the work: [me, family, a professional].
Also deliver: a materials and tools list with quantities and rough cost, the steps in the right order with time per step, safety points and any permit or neighbour/landlord approvals to check, what to do first if something goes wrong, and a progress checklist I can tick off.

5 · Gemini game brief

A 2D arcade racing game with a vertical scrolling road: dodge traffic, collect boost and fuel pickups, and reach a finish line after about two minutes.

6 · Copilot game brief

A 2D vertical air-fighter shooter: waves of enemy aircraft, power-ups, a mid-level mini boss and a final boss.

7 · Mistral game brief

A 2D maze chase game: collect every pellet in a labyrinth while avoiding patrolling enemies, with a power-up that lets you turn the tables for a few seconds. Use an original title and original characters.

8 · ChatGPT game brief

A 2D platformer: run and jump through one themed level with moving platforms, collectibles, enemies to avoid or defeat, a checkpoint and a boss at the end. Use an original hero and an original title.
