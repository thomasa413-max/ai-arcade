How it is run

Delivery discipline matters as much as the games, so each build follows the same small process.

  1. One briefThe same requirements for every platform: one HTML file, touch and keyboard, sound, one complete level, landscape and portrait.
  2. Time-boxed buildEach game gets a fixed number of iterations. Time, prompts and cost are logged.
  3. Test on a phoneEvery game is opened on a real phone and desktop before it is listed.
  4. Score and publishScored on the six criteria above, with notes on what worked and what needed fixing.

The shared brief is on the build kit page.
